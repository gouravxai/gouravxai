### 3. **TIMELINEVIZ** — Emotion Timeline Visualization
**Live Demo:** [timelineviz-using-cnn-and-bilstm-wcg7jujqmruxxylqzc2azy.streamlit.app](https://timelineviz-using-cnn-and-bilstm-wcg7jujqmruxxylqzc2azy.streamlit.app/) | **Repo:** [GitHub](https://github.com/gouravxai/TimeLineViz-using-CNN-and-BiLSTM)

Paste long-form text. Get a timeline showing how emotions evolve sentence-by-sentence. Not one emotion label for the whole text—a journey.

**Architecture:**
- CNN layer for local feature extraction
- Bidirectional LSTM for sequence modeling
- Trained on GoEmotions dataset (28 emotion classes)
- Plotly visualization of emotional arc

**Key Features:**
- Sentence-level emotion prediction
- Interactive emotion timeline graph
- Confidence scores per prediction
- Real-time inference (<1s)

**Tech:** PyTorch, CNN + BiLSTM, GoEmotions, Plotly, Streamlit

**Performance:**
- **Model Accuracy:** 44% on 28-way classification (solid baseline for high-cardinality task)
- **Dataset:** GoEmotions (27K+ samples, 28 emotions)
- **Architecture:** Hybrid CNN+BiLSTM (shows understanding of both architectures)

## 🚀 Featured Projects

### [ANN vs CNN — PyTorch](https://github.com/gouravxai/ANN-VS-CNN-PYTORCH)
Built and compared artificial neural networks and convolutional neural networks from scratch using PyTorch on the MNIST dataset.
- **Results:** CNN accuracy: 99.05% | ANN accuracy: 97.69%
- **Key techniques:** Batch normalization, dropout, learning rate scheduling, model comparison
- **Stack:** PyTorch, NumPy, Matplotlib

### [TimelineViz](https://github.com/gouravxai/timelineviz)
Interactive sentiment analysis tool for long-form text. Chunks documents and visualizes sentiment flow over time.
- **How it works:** Text chunking → VADER sentiment scoring → Plotly interactive visualization
- **Use case:** Analyze tone and emotional trajectory in articles, reviews, earnings calls
- **Stack:** VADER, Plotly, Pandas

### [Trader Sentiment Analysis](https://github.com/gouravxai/trader-sentiment-analysis)
NLP pipeline extracting actionable market sentiment from trader discussions and financial forums.
- **Goal:** Bridge gap between retail sentiment and price movements
- **Techniques:** Text preprocessing, sentiment extraction, trend analysis
- **Stack:** NLTK, Pandas, Scikit-learn

### [Emotion Detection — Text Classification](https://github.com/gouravxai/emotion-detection-analysis)
Multi-class emotion classification using classical NLP and machine learning.
- **Approach:** Bag-of-Words vs TF-IDF vectorization + Naive Bayes classifier
- **Comparison:** Evaluated both feature extraction methods for accuracy and interpretability
- **Stack:** Scikit-learn, NLTK, Pandas

### [House Price Advanced Regression](https://github.com/gouravxai/House-Price-Advanced-Regression)
Kaggle housing dataset with advanced feature engineering and model comparison.
- **Techniques:** Feature engineering, outlier detection, cross-validation, hyperparameter tuning
- **Models tested:** Linear Regression, Ridge, Lasso, XGBoost
- **Stack:** Scikit-learn, XGBoost, Pandas, NumPy

### [EDA & Visualization Projects](https://github.com/gouravxai/eda-visualisation-projects)
Exploratory data analysis and insights on various datasets with polished visualizations.
- **Covers:** Statistical analysis, distribution patterns, correlation heatmaps, trend identification
- **Stack:** Pandas, Matplotlib, Seaborn, NumPy
